# RECS 管理コンソール

リモート始動阻止装置（RECS）の管理画面。車両の位置確認と、始動阻止のON/OFFを行う。

- Next.js 15 / Vercel / Upstash Redis
- 地図は OpenStreetMap（APIキー不要）

---

## 仕組み

```
車載器（ESP32-S3 + SIM7080G）
   │  5分ごとに「位置・リレー状態」をPOST
   ▼
SORACOM（LTE-M）
   ▼
/api/device/report  ──返事──▶  {"r":あるべきリレー状態, "i":次の報告までの秒数}
   │
Upstash Redis（車両の状態・位置履歴・操作履歴）
   ▲
管理画面（ログイン必須） … 一覧・地図・阻止ON/OFF・操作履歴
```

- 指令は「命令」ではなく「あるべき状態」で持つ。通信が1回抜けても次の報告で必ず揃う。
- 阻止ONを押すと「反映待ち」→ 車載器が次に報告して反映すると「始動阻止中」になり、履歴に「車両で確認」が残る。
- 15分（報告間隔×3）通信がない車両は「通信途絶」と表示する。

## Vercelへの公開手順

1. このフォルダをGitHubのリポジトリに入れる
2. Vercelで「Add New → Project」からそのリポジトリを選ぶ
3. Vercelの Storage から **Upstash (Redis)** を作成してプロジェクトに接続する
   （`UPSTASH_REDIS_REST_*` か `KV_REST_API_*` の名前で自動で入る。どちらでも動く）
4. Settings → Environment Variables に以下を設定してデプロイ

| 変数名 | 内容 | 例 |
|---|---|---|
| `ADMIN_PASSWORD` | 管理画面のパスワード | 長めの文字列 |
| `SESSION_SECRET` | ログイン用の秘密鍵（32文字以上のランダム文字列） | |
| `DEVICE_KEY` | 車載器がAPIを叩くときの鍵 | 長めのランダム文字列 |
| `UPSTASH_REDIS_REST_URL` | Upstashの接続先 | 手順3で自動 |
| `UPSTASH_REDIS_REST_TOKEN` | Upstashのトークン | 手順3で自動 |
| `REPORT_INTERVAL_SEC` | 車載器の報告間隔（秒）。省略時300 | 300 |

> Upstashを設定しないと、データはメモリに入るだけでデプロイのたびに消える（手元テスト用の動き）。

## 実機なしで動作確認（シミュレータ）

偽の車載器を走らせて、管理画面の操作が車に届くかを確認できる。

```
node scripts/sim-car.mjs --url https://<あなたのURL>.vercel.app --key <DEVICE_KEY> --cars 3 --every 5
```

管理画面で車を選んで「始動阻止ON」→ シミュレータに「指令受信 → リレー ON」と出て、画面が「始動阻止中」になればOK。

## 車載器が守る通信ルール（ファーム担当向け）

**POST** `https://<URL>/api/device/report`

ヘッダ
- `content-type: application/json`
- `x-device-key: <DEVICE_KEY>`

本文（JSON）

| キー | 型 | 内容 |
|---|---|---|
| `id` | 文字列 | 車両ID（英数字・`-`・`_`、32文字まで）。SORACOM Beam経由ならIMSIが自動で使われるので省略可 |
| `relay` | 0/1 | **今の**リレー状態（1=始動阻止中） |
| `fix` | 0/1 | 測位できたか |
| `lat` / `lng` | 数値 | 緯度・経度（fix=1のときだけ使われる） |
| `rssi` | 数値 | AT+CSQ の値（0〜31、99=不明） |
| `fw` | 文字列 | ファームのバージョン |

返事

```json
{"r":1,"i":300}
```

- `r` … あるべきリレー状態。車載器はこれに合わせてGPIO4を切り替える
- `i` … 次の報告までの秒数

**車載器側で必ず守ること**
1. `r` を受け取ったら、その値を**フラッシュ（NVS）に保存**する。電源が落ちて再起動しても、保存値でリレーを復元する（通信できるまで阻止が外れないように）。
2. 通信に失敗したときは、保存値のまま維持して次の報告を待つ（勝手に解除しない）。
3. 起動直後はまずGPIO4をLOWにしてから、保存値を読んで設定する。
4. GPSと通信は同時に使えないので、「測位 → GNSS停止 → 通信」の順で行う。

## セキュリティ上の注意

- `DEVICE_KEY` は全車載器で共通。量産時は **SORACOM Beam** を使い、鍵をBeam側のヘッダ設定に持たせて車載器には持たせないのが望ましい（BeamがIMSIヘッダを付けるので、車両IDのなりすましも防げる）。
- ログイン時の「担当者名」は自己申告。担当者ごとのアカウント分けは今後の拡張。
- パスワードと鍵はGitHubに上げない（`.env*` は `.gitignore` 済み）。
